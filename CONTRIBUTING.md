# Contributing

Thanks for helping test Navimow HA Pro.

## Useful bug reports

Please include:
- Home Assistant version
- Navimow model
- Integration version
- What you expected
- What actually happened
- Relevant redacted logs
- Whether the official Navimow app behaved differently at the same time

Never include passwords, tokens, MQTT credentials, serial numbers, precise GPS
coordinates, or other private account data in a public issue.

## Pull requests

Keep changes focused and avoid unrelated formatting churn. If a change affects mower
commands, map/trail logic, schedules, or authentication, explain how it was tested.
