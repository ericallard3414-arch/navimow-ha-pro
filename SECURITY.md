# Security

Please do not post Navimow account credentials, OAuth/private tokens, MQTT credentials,
serial numbers, precise GPS coordinates, complete diagnostics, or unredacted Home
Assistant backups in public GitHub issues.

When reporting a bug, prefer Home Assistant diagnostics and logs after reviewing and
redacting any personal or location information.

For a security-sensitive report, contact the repository owner privately through the
contact method configured on the GitHub repository instead of opening a public issue.
